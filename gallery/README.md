# 角色圖庫

所有角色圖片集中於此，第一層以角色名稱分類；同一角色的世界觀、服裝、風格或情境差異，再建立子資料夾。

```text
gallery/
  <角色名稱>/
    shared/              # 跨世界觀可共用
    <世界觀或風格>/       # 例如 01-艾弍大陸、02-北大、現代、奇幻
```

圖片檔旁可附上同名 Markdown，記錄 prompt、來源、所屬世界觀與備註。

## 命名規則

- 角色資料夾使用目前最常用的角色名稱，例如「布萊克」。
- 世界觀、服裝、風格與情境放在角色資料夾內，例如 02-北大、現代、奇幻。
- 有多個稱呼時，於角色資料夾的 README 註明別名，避免建立重複資料夾。
