# 小說寫作專區（novels/）

這個子區專門用來**寫小說（敘事正文）**，跟 `sets/`（世界觀與角色設定資料庫）以及其他目錄完全分開，不得混寫。

## 用途界線

- `sets/`：世界觀、角色卡、劇情線／編年紀事等**設定資料**。
- `novels/`：實際的**小說正文**與其寫作相關檔案。
- 兩邊各司其職。設定不寫進 `novels/`，正文不寫進 `sets/`。

## 寫作規則

寫作規則見 `novels/寫作規則.md`，寫任何正文前都要先讀並逐條遵守；作者當次訊息優先於該檔。

## 存放方式

- 每部小說一個子資料夾，內含各章正文。
- 章節命名與 frontmatter 等細節，待作者的寫作規則確定後再定案。

## 原則

- 忠實原則：改動既有正文前先問作者。
- 新增／刪除／搬移檔案後，執行 `python3 tools/gen_filemap.py` 更新 `FILEMAP.md` 並一起 commit。
