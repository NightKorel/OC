# 北境（艾弍大陸）小說重寫項目

依作者原文重寫、精修潤飾。世界即作者所稱的北境，對應 `sets/01-艾弍大陸`。本項目自成一區，設定與正文都放在這裡，跟 `sets/` 分開。

- `設定/`：這次重寫的設定基礎（作者提供的完整版，原封未改）。

  - `劇情摘要/各線劇情摘要.md`：各線事件摘要，含羅萊線、凱埃線、維耶線、襲擊當日與公會後續系列、返響線、搖盪線、彈指線、過往、苑線。
- `原文/`：作者的完整正文，待提供後按章切檔放此。
- `重寫/`：重寫成品放此，與原文分開。

## 讀取策略（省 token）

一個視窗一次只讀當下需要的：這份 README、要重寫的那一章原文、上一章已重寫的成品（顧連貫）、加該章點名的設定片段。避免整包設定全載。

完整正文到位後，會寫切章腳本放 `tools/`，把正文拆成一章一檔，每檔加 frontmatter（章號、故事內日期、地點、在場角色、關聯設定、一兩行摘要），並在此建各章索引表。
