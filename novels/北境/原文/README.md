# 原文（分批收取）

作者的完整正文，來源為一連串對話匯出，檔名開頭數字即全書閱讀順序。作者一次給五個檔，分批提供。

正文夾雜匯出標頭、「## Response:」分段與少量英文寫作筆記；已用 `tools/split_beijing.py` 抽出正文，按故事內日期地點戳記切成一場一檔，放 `切分/`。原文檔為權威來源，原封保留。

## 切分結果（`切分/`）

腳本生成，勿手改；改動請改腳本後重跑 `python3 tools/split_beijing.py`。

- `切分/<組>/正文/<場號>.md`：每場一檔，frontmatter（場號、來源、故事日期、時段地點、出現角色、狀態）加逐字正文。共 333 場。
- `切分/<組>/導演註.md`：作者括號指示與讀者論壇，抽出供重寫參考（逐字）。
- `切分/索引-原文順序.md`：重寫依此順序推進。
- `切分/索引-故事時間.md`：依故事內時間排序（各線時間會前後跳）。
- `切分/進度台帳.md`：重寫進度。

`出現角色` 為文字比對的提示，重寫時仍以實讀場景為準。
