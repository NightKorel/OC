# 艾弍大陸（第一套）

中世紀科技水準 ＋ 成熟魔法的大陸。四大勢力（人類赫門王國、精靈艾露菲、矮人杜瓦林、
獸人斯克珞）之上，北境擋著世界傷口「深淵」的侵蝕。故事主舞台在赫門北境的**邊境鎮**，
核心是一群**怨靈／願組織**出身、帶著創傷的角色，在此互相收留、療傷、變強。
