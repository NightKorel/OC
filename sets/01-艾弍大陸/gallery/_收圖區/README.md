# 收圖區（作者上傳用）

把參考圖／生成圖上傳到**這個資料夾**就好，不用管檔名和分類——
Claude 之後會 `git pull` 下來，幫忙改成規範檔名、搬進對應角色的資料夾、
並寫進角色卡與 STYLE.md。

## 怎麼上傳（GitHub 網頁）

1. 進到這個資料夾頁面
2. 右上 **Add file → Upload files**
3. 把圖片拖進去（一次可多張）
4. 下方 **Commit changes**（選 commit 到目前分支）

## 小提醒

- 若知道是誰，檔名帶個名字最好（如 `埃洛_1.png`、`羅爾_側臉.png`），
  不知道也沒關係，Claude 會依畫面判斷。
- 上傳後跟 Claude 說一聲「傳好了」，他就會拉下來整理。
