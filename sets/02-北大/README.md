# 北大

北境大學。主要現代世界觀，包含多個 IF 分支。

## 暫置設定

- [北大](北大/)：北境大學設定，暫時與 IF 分支、幽鬼往事並列。

## 同層設定

- [幽鬼往事](幽鬼往事/)：北大底下、與 IF 並列的設定。

## IF 分支

- [Noir](if/Noir/)：北大 IF 分支。
- [墜機](if/墜機/)：北大 IF 分支。
- [奈何](if/奈何/)：北大 IF 分支。

- world/：北大本體與 IF 分支的世界觀設定。
- characters/：角色卡。
- storylines/：劇情線與編年紀事。
- gallery/：生成圖與對應 prompt。
