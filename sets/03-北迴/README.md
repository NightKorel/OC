# 北迴

現代異能世界觀。角色們身為異能者，一邊做 VT，一邊對抗異常。

## 收錄內容

- `characters/00-角色設定總覽.md`：北迴、安可社其他成員與相關角色設定。
- `world/00-安可社世界觀設定.md`：異常、能者、能力體系與安可社。
- `world/01-任務系統設定.md`：異常處理、錨點儀器與任務流程。
- `world/02-錨組織架構與異變.md`：組織架構與異變徵兆。
- `world/03-園區與生活.md`：園區配置與日常生活。
- `world/04-直播與粉絲文化.md`：直播文化與觀眾互動。

- `storylines/`：劇情線與編年紀事。
- 角色圖片統一收於根目錄 `gallery/<角色名稱>/`。
