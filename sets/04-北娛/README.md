# 北娛

北境娛樂。角色們身為演員的現代世界觀。

## 收錄內容

- `world/00-世界觀與配角.md`：娛樂圈 AU 的世界觀、組織、時間基準與配角設定。
- `characters/00-主要角色設定.md`：布萊克、修、羅爾、維伊、埃洛與耶里昂。
- `storylines/00-完整時間線.md`：2022 年以前的角色時間線。
- `storylines/01-布萊克作品與斷橋.md`：布萊克的代表作與《斷橋》劇情簡要。
- `storylines/02-斷橋與後續劇情.md`：2022 年至 2023 年的劇情記錄。

- 角色圖片統一收於根目錄 `gallery/<角色名稱>角色圖/`。

## 設定狀態

- 時間點：依各資料檔案記錄。
- 核心前提：角色們身為演員的現代世界觀。
- 已確定：目前已收錄內容。
- 待補：後續新增或修訂時在此列註記。
