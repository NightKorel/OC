## 收錄內容

- `world/00-世界觀與北境工作室.md`：靈體、委託、除靈方式與北境工作室。
- `characters/00-角色設定總覽.md`：主要角色與加入順序。

- `storylines/`：劇情線與編年紀事。
- 角色圖片統一收於根目錄 `gallery/<角色名稱>角色圖/`。
